# АЛЛЕЯ — сайт-заглушка для портфолио

Вымышленный бренд воды из айсбергов Ньюфаундленда. Сезон закрыт: страница —
погружение от верхушки айсберга до дна, внизу запись на следующий сезон.

Next.js 16 (App Router) + TypeScript + Tailwind 4, статический экспорт без бэкенда.

## Команды

```bash
npm install
npm run dev      # разработка: http://localhost:3000
npm run build    # статическая сборка в папку out/
```

Для GitHub Pages (сайт в подпапке репозитория):

```bash
NEXT_PUBLIC_BASE_PATH=/alleya npm run build
```

## Где что

- `src/app/page.tsx` — вся страница по секциям (над водой → 0 м → −30 … −240 м → подвал).
- `src/lib/iceberg.ts` — геометрия айсберга: грани генерируются с фиксированным зерном.
- `src/components/` — айсберг, волна, карта, индикатор глубины, счётчик, форма.
- Глубина в индикаторе считается по отметкам `data-depth` у секций.
- Форма работает только в браузере: адрес сохраняется в localStorage, никуда не отправляется.
